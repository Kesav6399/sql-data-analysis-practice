# Employee Data SQL Analysis

## Objective
This case study analyzes employee data using SQL to identify salary patterns, workforce distribution, and department-wise insights.

## Dataset
The dataset contains employee details including:
- Employee ID
- Employee Name
- Department
- Salary
- City
- Joining Date

## Key Analysis Performed
- Department-wise employee count
- Average salary by department
- Top 5 highest paid employees
- Employees earning above average salary
- Salary category analysis
- City-wise employee distribution
- Recently joined employees

## Key Insights
- IT department has the highest average salary.
- Hyderabad has the highest employee concentration.
- Salary categorization helps understand compensation distribution.
- Employees above average salary can be identified for performance and compensation review.

## Skills Demonstrated
- SQL Query Writing
- Data Analysis
- Aggregation
- Filtering
- Subqueries
- CASE Statements
- Business Insight Generation

## Conclusion
This case study demonstrates how SQL can be used to analyze employee data and generate meaningful business insights for decision-making.
